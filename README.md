# Crowdsource-Civic-Reporting-Resolution-System
A web-based platform that enables citizens to report civic issues such as potholes, garbage, water leakage, and streetlight failures. The system helps authorities track, manage, and resolve complaints efficiently while improving communication between citizens and government bodies.
# Features
User Registration & Login
Report Civic Issues with Details
Complaint Tracking System
Admin Dashboard for Managing Complaints
Status Updates for Issue Resolution
Secure Data Management
Technologies Used
Frontend: HTML, CSS, JavaScript
Backend: ASP.NET / C#
Database: SQL Server
Server: IIS
Purpose
This project aims to create a smart and digital solution for improving civic issue management by enabling efficient reporting and faster resolution of public complaints.
